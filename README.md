# Riptide Hop

Full-colour Python 3 neon **tide-hopper** arcade for [ElbowOS](https://x.com/ElbowOS).
Hop the coral banks, ride teal drift-logs, dodge coral boats and gold fish.

Not a clone of Volt Trace / Orbit Hook — new mechanic, teal/coral/gold palette, vertical lane layout.

## Play

```bash
pip install -r requirements.txt
python3 riptide_hop.py --play
```

Arrow keys hop and sidestep. `R` restarts. `Esc` quits.

## Autoplay reel (9:16)

```bash
python3 riptide_hop.py
```

Writes a 15s 1080×1920 H.264 reel (title + score + `x.com/ElbowOS` burned in).
Default output: `/home/workdir/artifacts/RIPTIDE_HOP_ElbowOS.mp4`
